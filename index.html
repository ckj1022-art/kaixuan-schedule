    開瑄成長時刻表

    請輸入檢視密碼。

    第一次使用：還沒有課表資料。請管理者設定檢視密碼，並貼上 GitHub 金鑰（README 有說明怎麼申請）。

    管理登入

    貼上 GitHub 金鑰（只限這個 repository、權限為 Contents 讀寫）。修改會直接存回 GitHub，大約 1 分鐘後其他人重新整理就會看到。

    設定

    更換檢視密碼後，課表會用新密碼重新加密存回 GitHub。記得把新密碼告訴老師。

    選一種外觀，所有打開這個網頁的人都會看到同一種。

    修改會自動儲存在這個網頁。想留一份備份或交給其他老師時，按「複製資料」；把備份貼回下方再按「匯入」即可還原。

    修改時間

    改的是這一節的鐘點，整週每天都會跟著變。
